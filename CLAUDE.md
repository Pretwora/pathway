# Pathway — трекер целей с накопительным эффектом

> **Решено владельцем, не поднимать:** название Pathway (в магазинах — «Pathway - tracker»), палитра «Фирменная» из логотипа, тёмная тема, звук победы, «цель» в интерфейсе, без встроенных шаблонов.

Мобильное приложение (iOS + Android) для целей, к которым идут по чуть-чуть: «тысяча отжиманий», «3000 страниц». Пользователь тапает `+10` после каждого подхода, значения суммируются, при достижении цели — празднование и уход в архив.

## Главный сценарий

Человек между подходами достаёт телефон **одной рукой**, тапает `+10` три раза, убирает в карман. Четыре секунды. Любое решение проверяется этим сценарием: если оно добавляет шаг между запуском и кнопкой — оно неверное.

## Незыблемые правила

1. **Прогресс не хранится — вычисляется** как `SUM(entries.amount)`. Никакого кэшированного поля `current` в таблице `goals`. Расхождение счётчика и истории убивает доверие ко всему продукту.
2. **Одна активная цель — инвариант базы**, а не проверка в UI. Частичный уникальный индекс `one_active_goal`. То же с днями: `one_entry_per_day`, одна запись на день.
3. **Цвета и отступы — только из `src/ui/tokens.ts`.** Литерал `#2F86FF` или `padding: 24` в компоненте — ошибка.
4. **Домен (`src/domain/`) не знает про React и SQL.** Чистые функции, тестируются без эмулятора.
5. **Экран не ходит в базу.** Экран → стор → репозиторий → база.
6. **Тап пишется в базу сразу, и складывает база.** Не копим в памяти по таймеру — приложение убьют, данные пропадут. И не читаем `amount` в JS, чтобы записать сумму обратно: три быстрых тапа затрут друг друга. Только `UPSERT` с `amount = amount + ?`.
7. **Записи всегда положительные.** Сделать минус невозможно, поэтому прогресс не уходит в минус — не проверкой, а тем, что нечему. Ошибку исправляют правкой дня, ноль убирает день.
8. **Единицы измерения нет.** Поле `description` — свободное описание цели, оно нигде не подставляется в строку. Счётчик говорит «осталось 5» — без слова: склонять по числу слово, которое ввёл пользователь, невозможно.
9. **Шаблонов нет.** Форма новой цели всегда пустая, подсказки — в плейсхолдерах. Возвращать список готовых целей — только по решению владельца.
10. **Новый блок не переписывает домен предыдущего.** Если пришлось — остановиться и обсудить.

## Стек

Expo + TypeScript, expo-router, expo-sqlite + Drizzle, Zustand, reanimated, react-native-svg, expo-haptics, expo-audio. Без бэкенда, без аккаунтов, без аналитики.

## Тон интерфейса

Тёмный, собранный. Фон — глубокий синий `#0A0F1A`, не чистый чёрный; текст не чистый белый. Акцент — синий `#2F86FF`, градиент логотипа (синий → голубой → зелёный) только на тропе прогресса, в конфетти и на полоске результата в архиве. Теней нет — только границы и разница яркости поверхностей. Цифры и заголовки — Unbounded, остальное — Manrope.

## Идентификаторы

Пакет `com.sgrigoriev.pathway`, схема ссылок `pathway://`, база `pathway.db`, файл копии `app: "pathway"`. Под иконкой — «Pathway», в магазинах — «Pathway - tracker».

## Сборка

Только локально, без облачных сервисов сборки. Android — на своей машине (`docs/08-windows.md`), ключ: `%USERPROFILE%\.android-keys\pathway-upload.jks`, alias `pathway`, пароль — в переменной окружения пользователя `PATHWAY_KEYSTORE_PASSWORD`. Подписываем готовый APK через `apksigner`: каталог `android/` пересоздаётся `expo prebuild`. iOS — на Mac в Xcode, по шагам в `docs/07-публикация.md`.

Иконка: исходник логотипа — растровый `assets/logo-source.png`. Слои адаптивной иконки режет `python assets/logo-layers.py` — после правки масштаба смотреть контрольный лист масок, который он печатает: Android показывает только центральные 66 % слоя.

## Язык

Интерфейс и вся коммуникация — русский. В коде — `goal`, в интерфейсе — «цель» (женский род: «Новая цель», «Цель достигнута», «Цель закрыта досрочно»).
