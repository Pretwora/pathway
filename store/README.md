# Картинки для страниц приложения в магазинах

Сняты с релизной сборки 1.0.0 на эмуляторе Pixel 7, демо-данные. Строка состояния убрана, рамка телефона и подписи — в стиле приложения (палитра «Фирменная», Unbounded и Manrope).

## App Store (`app-store/`)

| Папка | Размер | Для чего |
|---|---|---|
| `6.9-inch/` | 1320 × 2868 | iPhone 6.9" — основной обязательный набор |
| `6.5-inch/` | 1242 × 2688 | iPhone 6.5" — если App Store Connect попросит |

PNG без прозрачности. Иконку App Store берёт из самой сборки, отдельно её не загружают. Сборки под iOS пока нет: её нельзя сделать на Windows, нужен Mac с Xcode.

## Подписи на скриншотах

1. **Тапни +10 после подхода** — Кнопки под большой палец — попадаешь не глядя
2. **Празднуй финиш** — Конфетти, итог и карточка для друзей
3. **Своя цель за 10 секунд** — Название, число и три кнопки шага
4. **Все цели — в архиве** — Результат каждой: добитой и закрытой досрочно
5. **Большое из малого** — Одна цель за раз. Без рекламы и аккаунтов
